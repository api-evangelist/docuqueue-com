DocuQueue is an AI‑powered document automation platform designed for the agent era. It offers a REST API and MCP integration that lets developers generate, fill, and batch PDFs, contracts, invoices, certificates, and other documents on demand. Built by Arun in India, the service provides a free tier with initial credits and scales with usage, targeting legal, sales, HR, real‑estate, and other enterprise workflows.

**Areas:** Company · AI · DocumentAutomation · PDF · RESTAPI · MCP
